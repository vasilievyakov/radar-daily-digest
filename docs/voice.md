# Голос продукта

Спецификация того, что человек реально прочитает. Форматтеры собираются по ней, а не по умолчаниям библиотеки.

Примеры ниже — образцы формы, а не данные. Ни одна строка отсюда не попадает в прогон: форматтер подставляет то, что лежит в Signal, и падает, если поля пустые.

Общие правила: без эмодзи, литературный русский, без антитез вида «не X, а Y», без канцелярита и оценочных прилагательных. Система говорит о деле читателя, а не о себе.

---

## 1. Строка уведомления на заблокированном экране

Сорок символов. В большинстве дней человек прочитает только её и не откроет сообщение. Она обязана нести главный факт дня.

Обычный день — берётся из `headline` сигнала ранга 1, усечение по границе слова:

```
Anthropic отключает claude-3-opus 15 окт
```

Тихий день:

```
Сегодня без изменений
```

Падение прогона:

```
Прогон не завершился
```

Запрещено: название бота, дата прогона, слово «дайджест», номер прогона, счётчик пунктов.

## 2. Тихий день

Сообщение про день читателя. Статистика проверки идёт после, мелким блоком, и служит доказательством, а не содержанием.

Тишина заполняется ближайшими сроками из уже извлечённых фактов — тем, что человек сам запланировал забыть.

```
Сегодня в вашем стеке ничего не изменилось.

Ближайшее:
15 октября, через 59 дней — отключается claude-3-opus
1 ноября, через 76 дней — новые лимиты Tier 1 в OpenAI API

Проверено 14 источников, 23 материала отклонено. Лог прогона.
```

Если ближайших сроков в корпусе нет, блок отсутствует целиком. Пустой заголовок «Ближайшее» не выводится.

## 3. Первый пункт обычного дня

Позиция 1 получает разворот, позиции 2–5 живут одной строкой каждая. Внимание распределено неравномерно, и витрина следует за этим.

```
Anthropic отключает claude-3-opus

15 октября, через 59 дней. Запросы к модели начнут возвращать ошибку;
на замену предложен claude-opus-4.

Почему это важно: модель используется в двух ваших проектах.

«claude-3-opus will be retired on October 15, 2026»
docs.claude.com/en/docs/about-claude/model-deprecations

Третий раз с мая Anthropic объявляет отключение с двухмесячным
предупреждением. Показать три записи.
```

Строки 2–5:

```
OpenAI поднимает лимиты Tier 1 — с 1 ноября, через 76 дней
n8n 1.62.0 — исправлена потеря данных в Webhook-ноде
```

## 4. Даты

Везде, где выводится дата, рядом стоит расстояние до неё: «15 октября, через 59 дней». Читатель не должен считать в уме.

Прошедшие даты: «1 июня, 77 дней назад». Сегодня: «сегодня». Завтра: «завтра».

Дата, извлечённая без года и восстановленная по контексту, помечается: «15 октября (год не указан в источнике)». Дата, которой в источнике нет, выводится строкой «дата отключения в источнике не указана» и ничем не заменяется.

## 5. Футер с недоступными источниками

Спокойный тон. Отказ источника — рабочая ситуация, а не тревога.

```
Два источника не ответили: Cursor changelog, MCP servers. Лог прогона.
```

Источник, вернувший HTTP 200 без единой записи, называется отдельно, потому что это другая поломка:

```
Cursor changelog ответил, но ничего не отдал.
```

## 6. Падение прогона

Отдельный тип сигнала, а не молчание. Система, которая внятно докладывает о собственном отказе, зарабатывает больше, чем система, которая никогда не признаётся.

```
Прогон 17 августа не завершился: сбой на стадии обогащения.

Собрано 34 материала, обработать не удалось. Последняя удачная
сводка — 16 августа. Лог прогона.
```

## 7. Последняя строка

Закрытие истории, если сегодня что-то закрылось. Система, которая только открывает нити и никогда их не закрывает, набирает вес.

```
Закрыто: миграция на Responses API завершена, история велась 12 дней.
```

Если закрывать нечего — последней строкой идёт ссылка на лог прогона.

## 8. Что на экран не выводится

- Число важности 0–100. Порядок и есть выраженная оценка; число превращает суждение в ложную точность и приглашает спорить, почему 87, а не 91.
- Обоснование ранга. Производится на стадии 6 и живёт в одном касании, а не в утренних шестидесяти секундах.
- `duplicates_count`. Восемь перепечаток интересны строителю системы.
- Метка `not_found_in_corpus`. Метка, которая ничего не меняет в прочтении, занимает строку и учит пропускать метки вообще. Контекст показывается тогда, когда он меняет интерпретацию сегодняшнего события.
- Идентификаторы прогона и сигнала в теле сообщения. `signal_id` уходит в подвал каждой поверхности мелким шрифтом: он нужен, чтобы на демонстрации было видно, что три поверхности показывают одну запись.

## 9. Проверка

Шестьдесят секунд измеряются секундомером по настоящему тексту, а не считаются в таблице метрик. Пять пунктов по две строки дают 130–180 слов, и весь бюджет уходит на чтение, ничего не оставляя пониманию.

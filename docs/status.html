Что планировали

Автономный агент, который каждое утро обходит источники, находит изменения в инструментах разработчика и присылает сводку, где под каждым утверждением стоит дословная цитата из первоисточника.

  • Конвейер из семи стадий: сбор, нормализация, склейка, фильтр значимости, извлечение фактов, поиск прецедентов в своём корпусе, публикация.
  • Три запрета исполняемым кодом, а не просьбой к модели: факт без дословной цитаты не публикуется; фразу «третий раз с мая» ставит код по числу прецедентов; обобщение без числа запрещено.
  • Накопленный корпус событий, чтобы сегодняшнее изменение можно было поставить в ряд с прошлыми.
  • Четыре поверхности над одним контрактом: веб, Telegram, почта, план родного клиента для macOS.
  • Полный журнал действий и надзиратель, который заметит, что агент замолчал.
  • Запуск по расписанию, без человека.

Совет директоров предлагал сократить объём — убрать клиент, почту, вторую тему, векторные представления. Решение было делать всё.

Выводдля эфира

Что из этого показывать

Сильнейшее в системе — не карточки. Карточки умеет и чат. Сильнее всего страница лога прогона: воронка 104 → 80 → 48 → 33, у каждого отсеянного материала названа причина, рядом колонка «Сеть» с ответами серверов, и строка о стоимости, которая сама себя проверяет — «$0.19, без кэша ответов та же работа стоила бы $0.58».

Чат не может показать, о чём он промолчал. Агент обязан — и это вся разница, которую стоит показать в зале.

И финальный ход: прогон, запущенный со сцены, кладёт сообщение на телефон. Надзиратель после него говорит «прогон завершён, доставка выполнена» — за все предыдущие четырнадцать прогонов в этом поле стояла пустота.
